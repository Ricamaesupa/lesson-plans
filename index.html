How to use this in class

  1. Find the session by number or date — or type a topic in the search box on a student page.
  2. Read the Components first, so everything is ready before the student arrives.
  3. Follow the step-by-step build, then the test checklist. Screenshot the working version at 65–80 minutes.
  4. Write the CIY report note from the Success check.

Student first names only are used on this site. Session counts and dates come from the plans as written — Yim’s 265-session count is still to confirm, and Gin’s MIT App Inventor track is an exploration, not a CIY-assigned track.
