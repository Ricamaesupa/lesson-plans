Session 4JS: Form validation + messageSat 9 Jan 2027
Sat 9 Jan 2027 | Website 1

Objective: Validate the contact form in JS and show a success message without reloading. Materials: VS Code, her contact form. Components / codes:

const form = document.querySelector('form');
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const name = document.getElementById('name').value.trim();
  const email = document.getElementById('email').value.trim();
  if (name === '' || email === '') { alert('Please fill in name and email.'); return; }
  if (!email.includes('@')) { alert('Please enter a valid email.'); return; }
  alert('Thank you, ' + name + '! Your message was sent.');
  form.reset();
});

Step-by-step: Add submit listener, explain preventDefault(). Check name not empty, email has @. Success: thank-you with name, then reset. Test empty, bad email, good submit. Test: Empty blocked, bad email blocked, good shows thank-you + clears. Success check: Aom can test all three cases and explain each. Homework: Choose next feature: gallery filter OR image lightbox.
