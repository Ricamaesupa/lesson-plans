MIT App Inventor — Game Curriculum

The levels the session reports follow. 6 levels, 5 mini projects + 1 capstone game per level, 36 projects in total — game development only, all block-based, no text programming.

Each project has a game idea, what you learn, Components, Blocks, how to test, and a success check. Suggested pacing: 2 sessions per mini project, 4 per capstone — 14 sessions per level, 84 sessions for the whole curriculum. Draft 18 Nov 2026 — it will be updated to match the curriculum in the CIY system.

Level 1 — Apprentice

Who it is for: First games. No experience needed. Designer + Blocks basics, events, variables, simple conditionals.

Skills by the end: Button / Label / Image, when Button.Click, variables, if, timers, sounds, one screen per game.

Level 2 — Enthusiast

Who it is for: Finished Apprentice capstone. Ready for score + lives + levels.

Skills by the end: Lists + TinyDB, Canvas + sprites + collision, Clock speed, levels, sounds, multi-screen.

Level 3 — Professional

Who it is for: Finished Enthusiast capstone. Ready for gravity, physics, and pass-and-play.

Skills by the end: Gravity / jump, platform collision, Breakout physics, tower defence waves, procedures, pass-and-play.

Level 4 — Master

Who it is for: Finished Professional capstone. Ready for data, save systems, and smart opponents.

Skills by the end: TinyDB save / load, lists + sorting (insertion order — no true sort block), procedures with return, AI opponent (rule-based), Canvas charts (draw blocks — no chart component exists).

Level 5 — Boss

Who it is for: Finished Master capstone. Ready for connected, real-time, and data games.

Skills by the end: Bluetooth (2 phones), Web APIs (no-key), sensors, real-time play, leaderboards (local + Web with fallback).

Level 6 — GOAT

Who it is for: Finished Boss capstone. Ready to build, polish, and publish a real game.

Skills by the end: Game tools, sensors / ML (exploration), shop / coins, studio workflow, publishing, portfolio.

When to move up a level

  • Apprentice → Enthusiast: Capstone 1.6 works — all 3 games play, best scores save.
  • Enthusiast → Professional: Capstone 2.6 works — all 5 games play, best scores save.
  • Professional → Master: Capstone 3.6 works — all 3 levels finishable, best time saves.
  • Master → Boss: Capstone 4.6 works — map → battle → puzzle → shop → boss, save survives closing.
  • Boss → GOAT: Capstone 5.6 works — full multiplayer match with a real opponent, leaderboard works.
  • GOAT complete: Capstone 6.6 works — game published (or shared with approval) + portfolio presented.
  • Do not move up on a half-finished capstone. Fix the top bug first, then move up.
