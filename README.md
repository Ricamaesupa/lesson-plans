## How it works

Static site, no build step, no database. Open `index.html`, pick a student, search a topic, open a session.

Every session: 0–10 plan on paper, 10–20 demo, 20–65 build, 65–80 test & fix + screenshot, 80–90 share & homework (one small task only).
